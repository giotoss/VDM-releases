# VDM – Video Download Manager : téléchargements

Ce dépôt contient uniquement les **installateurs** de VDM. VDM l'interroge au démarrage pour
proposer automatiquement les nouvelles versions.

➡️ **[Télécharger la dernière version](https://github.com/giotoss/VDM-releases/releases/latest)**

| Système | Fichier |
|---|---|
| Windows 10/11 (64 bits) | `VDM-Setup-<version>-Windows.exe` |
| macOS (Apple Silicon) | `VDM-<version>-macOS.dmg` |
| Linux Debian / Ubuntu / Mint | `vdm_<version>_amd64.deb` |
| Autres Linux | `VDM-<version>-Linux-amd64.tar.gz` |

Chaque fichier est accompagné de son empreinte `.sha256`, vérifiée par VDM avant toute mise à jour.

**Usage légal** : ne téléchargez que des contenus dont vous avez les droits ou que l'auteur autorise.
